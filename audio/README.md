- `station-02.mp3`

אחר כך לשלוח לי את הקבצים ואני אמיר אותם ל-mp3 קל ואכניס אותם.

**הנגן מופיע מעצמו** ברגע שהקובץ קיים. אם הקובץ חסר, הבלוק פשוט לא מוצג.
