# הקאמבק · הדרך חזרה

מסע דיגיטלי אינטראקטיבי לזוגות. חמש תחנות, כרטיס אישי בסוף כל אחת, ומפה משותפת בסוף.

- `index.html` — עמוד הבית, ההקדמה, המפה
- `station-01.html` … `station-05.html` — התחנות
- `content-01.js` … `content-05.js` — **בנקי התוכן. אלה הקבצים לעריכה.**
- `engine.js` · `style.css` · `map.js` — המנוע והעיצוב

כל התשובות נשמרות ב-localStorage של הדפדפן בלבד. שום דבר לא נשלח לשרת.
